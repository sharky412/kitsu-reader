## Kitsu contribution guidelines

+ If you want to **fix bugs** or **implement new features** that **already have an [issue card](https://github.com/sharky412/kitsu-reader/issues):** please assign the issue to yourself and/or comment about it.
+ If you want to **implement a new feature:** open an issue or discussion first to ensure it will be accepted.
+ In case you want to **add a new manga source,** refer to the [parsers repository](https://github.com/KotatsuApp/kotatsu-parsers).

**Refactoring** and **developer-experience improvements** are also accepted. Please stick to the following principles:

+ **Performance matters.** When choosing between source code beauty and performance, performance should be the priority.
+ **Avoid adding new dependencies** unless required. APK size is important.
